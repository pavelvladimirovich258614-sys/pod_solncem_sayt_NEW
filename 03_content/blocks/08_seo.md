# 08. SEO-описания (meta title / meta description)

Источник: SCOPE § 5 (Технические требования: SEO — meta title/description/canonical/og на каждой странице). Лимиты: title ≤ 60 символов, description ≤ 160 символов. Подсчёт длины — UTF-8 символы (русские буквы считаются за 1).

## Назначение

Заполнить meta-теги для всех 9 страниц v1: главная + 5 направлений + 4 тура. Страницы-политики (ПД, cookie, оферта) — отдельно в Э7 (`SITE_LEGAL/`), здесь не дублируются.

## Формат

```
title:       "..."                                                (≤ 60 символов)
description: "..."                                                (≤ 160 символов)
canonical:   "https://pod-solncem.ru/<path>"
og_title:    = title
og_desc:     = description
keywords:    [...]                                                 (не обязательно для Google, но заполним для внутреннего учёта)
h1 (на странице, не meta): отличается от title — на странице h1 длиннее и «человечнее»
```

## Шаблон для будущих страниц

Если Masta Killa при сборке добавит страницы помимо этих 9, формат:

```
<page>:
  title: "{название страницы} — {главная выгода}"
  description: "{1–2 предложения: что получит турист, чем вы отличаетесь, как связаться}"
  h1: "{отличается от title, на странице «человечнее»}"
```

## Что в этом блоке — гипотеза и требует подтверждения

- **Цены в title/description туров** — гипотеза. Если цена изменится, мета-теги надо обновить синхронно. Перед публикацией — согласовать с Сергеем.
- **Список направлений в meta главной** — соответствует 4 страницам туров. Если в будущем добавится Египет — обновить.
- **Keywords** — не критичны для Google, но пригодятся для внутренней документации и Яндекс.Вордстат. Значения ориентировочные, не требуют точного подтверждения.
- **H1 на страницах направлений и туров** — мои формулировки, не из SCOPE. При сборке страниц (Э6) могут быть переписаны дизайнером. Это не блокирует публикацию мета-тегов.

## Заметки для следующих правок

- Все description начинаются с конкретной выгоды (страны, плюсы), а не с «турагентство предлагает». Это требование продающей подачи SCOPE § 3, перенесённое в SEO.
- Цены в title туров — спорное решение. С одной стороны, цена в title улучшает CTR. С другой — цена изменится, и мета-тег устареет. До согласования с Сергеем лучше держать. После согласования — синхронизировать с блоком 03_tours.md.
- Canonical для всех страниц = `https://pod-solncem.ru/<path>` (без trailing slash). Если домен ещё не направлен на Netlify — canonical должен быть обновлён после деплоя.
