## Решения владельца, которые действуют

- Hero-фото остаётся прежним (Greece), заменять не нужно.
- WhatsApp и Telegram в шапке подключаем последними, после получения контактов; сейчас это картинки без ссылок.
- Оценочные формулировки (например, «с любовью к путешествиям») не считаются техническими дефектами.

- Правило работы: одна фича — один worktree — один коммит — один деплой; сверка боевого сайта с `origin/main` перед правкой (с учётом CRLF/LF); при замене изображений всегда новое имя файла.
