# Под Солнцем — туристическое агентство

Одностраничный сайт турагентства «Под Солнцем». Это статический лендинг: посетитель выбирает направление или тур и переходит в Telegram для индивидуального подбора.

## Файлы

```
index.html          # весь сайт: HTML, CSS и JavaScript в одном файле
assets/images/       # локальные WebP-изображения (hero, направления, туры, отзывы)
assets/fonts/        # локальные WOFF2-шрифты (Onest, PT Serif, Caveat)
README.md            # описание проекта и чек-лист перед публикацией
```

Сборка, Node.js, npm, React, Astro и отдельные CSS/JS-файлы не нужны.

## Как открыть локально

1. Скачайте `index.html`.
2. Откройте файл двойным кликом в браузере.

Для локальной проверки можно также запустить в папке сайта:

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Что реализовано

- адаптивная версия для desktop, tablet и mobile;
- меню для мобильных устройств;
- hero-блок с полноэкранным travel-фото;
- направления и карточки туров;
- CTA в Telegram-бот `@coral_taganka_bot`;
- личная кнопка менеджера Анны;
- блок отзывов, FAQ-аккордеон;
- cookie-баннер и настройка согласий в `localStorage`;
- внутренние окна: политика ПД, cookies, согласие на обработку ПД, правовая информация и пользовательское соглашение;
- hover/focus-состояния и поддержка `prefers-reduced-motion`.

## Важное перед публикацией

Перед размещением сайта на домене нужно проверить и подтвердить:

1. Цены, рейтинги, бейджи и тексты отзывов — в коде они помечены `TODO`.
2. Номер турагента в ЕФРТА и режим работы.
3. Адрес и e-mail в футере: сейчас там есть пометка «уточняется» и технический e-mail.
4. Разрешение на публикацию фотографии менеджера Анны.
5. Изображения и шрифты уже локальные (`assets/images/`, `assets/fonts/`), внешних зависимостей от `postimg.cc` или Google Fonts нет.
6. Все телефоны, Telegram-ссылки и юридические документы после размещения на реальном домене.

## Публикация

Это статический сайт. Для публикации достаточно разместить `index.html` на любом статическом хостинге или веб-сервере (GitHub Pages, Netlify, Vercel, VPS с Nginx и т. п.).

Перед деплоем не меняйте файл без проверки на ширинах **320, 390, 430, 768, 1024, 1280 и 1440 px**.
