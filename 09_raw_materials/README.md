## Два ключевых свода, на которые опирается ТЗ

- **`05_ОТЧЁТЫ/КОНТАКТЫ_И_КОМПАНИЯ.md`** — все контакты, офисы, юрлицо, банковские реквизиты kupit-tyr.ru. **Не использовать как подтверждённые — требует проверки с Сергеем.**
- **`05_ОТЧЁТЫ/КОНТЕНТ_И_ПЕРЕНОС.md`** — что переносим / обновляем / исключаем из старого сайта. Зафиксировано по голосовому Сергея от 18.09.2026.

## Что из сырья уже использовано в ТЗ (v1.0)

- Из `01_СТРАНИЦЫ_САЙТА/about.html.md` — позиционирование и описание компании (зафиксировано как гипотеза).
- Из `01_СТРАНИЦЫ_САЙТА/index.md` — формулировки о направлениях, тоне, услугах.
- Из `01_СТРАНИЦЫ_САЙТА/turkey.html.md` + `egypt.html.md` + `oae.html.md` + `maldives.html.md` — карточки направлений.
- Из `СЫРЬЁ С КАНАЛА/04_АНАЛИЗ/summary.json` — топ-направления по частоте в канале.
- Из `СЫРЬЁ С КАНАЛА/04_АНАЛИЗ/hotels_candidates.csv` — кандидаты в отели (35 штук в каталоге `05_CONTENT/07_HOTEL_CATALOG/hotels-by-country.md`).

## Что НЕ использовано

- Конкретные цены из постов канала — помечены как непубликуемые (см. сессию Cline в HANDOFF).
- Все офисы kupit-tyr.ru (4 штуки) — нужна сверка с Сергеем, какие из них — новые.
- Банковские реквизиты старого ООО «Под Солнцем» (ИНН, ОГРН, расчётный счёт) — НЕ публикуются.
