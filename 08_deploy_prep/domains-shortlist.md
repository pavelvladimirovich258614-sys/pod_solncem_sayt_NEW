### Метод проверки доступности
- Прямой WHOIS через RDAP.org → для каждого TLD отдаёт свой registry RDAP endpoint.
- `.store` через radix.host RDAP: «is available for registration» — **надёжный ответ**.
- `.travel` / `.tours` через Identity Digital: 404 «Object not found» — сильный сигнал «свободен», но не 100% гарантия (Identity Digital иногда скрывает taken домены за DNSSEC-fence).
- `.ru` через любой публичный RDAP — **не отдаёт данных** (RU-CENTER/TCI RDAP закрыт, reg.ru — JS-gated). Реальная проверка возможна **только из личного кабинета reg.ru** (тот, через который покупали `pod-solncem.ru`).
